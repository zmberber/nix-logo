# nix-logo

The parametrized Nix logo as a Scalable Vector Graphics (SVG) file or string, generated by pure Nix (without nixpkgs!) code.

The default settings try to stay in spirit as close the original design(s) of the Nix logo by the original creators, with the changes being made due to inconsistencies of its [existing implementation](https://github.com/NixOS/nixos-artwork/tree/master/logo), namely alignment issues and ratio issues.

## lib

This flake outputs the following functions, each taking as input an attrset of options as described in the next subsection:
- `lib.mkSvg`:  Returns the logo in SVG format as a string.
- `lib.mkLogo`:  Returns a derivation that builds the logo as an SVG file.  Requires a `system` attribute in the input attrset.

### Options

| key        | Description                                                                                  | Type                               |
|------------|----------------------------------------------------------------------------------------------|------------------------------------|
| gap        | gap between the lambdas, gets cut away from the head of a lambda                             | float                              |
| thickness  | thickness of the lambda, but "radius", not "diameter"                                        | float                              |
| colors     | colors of each lambda, starting from the upright lambda, then counterclockwise               | list of strings (hex color values) |
| neck       | length of the "neck" of the lambda                                                           | float                              |
| resolution | value which must produce an integer when multiplied with each `gap`, `thickness`, and `neck` | integer                            |
| pad        | pad between the logo and the edges of the SVG bounding box                                   | float                              |


## packages

`nix build` builds the default package, and symlinks the result at `./result`.

### Variations

Run `nix build .#$VARIATION` to build one of the following pre-configured variations:

| `$VARIATION`          | Description                       |
|-----------------------|-----------------------------------|
| `nix-logo`            | default                           |
| `nix-logo-nogap`      | with no gaps between lambdas      |
| `nix-logo-black`      | in black                          |
| `nix-logo-white`      | in white                          |
| `nix-logo-pride`      | with pride colors                 |
| `nix-logo-trans`      | with trans colors                 |
| `nix-logo-styleguide` | modified version from style guide |
| `nix-logo-anarchy`    | smash the (OS-)state!             |

## Customization examples

### Package

```sh
nix build -f package.nix --argstr system x86_64-linux --arg gap 0.5 --arg colors '[ "#fb4934" "#b8bb26" "#fabd2f" "#83a598" "#d3869b" "#8ec07c" ]'
```

### To stdout

```sh
nix eval --impure --raw --expr 'import ./svg.nix { gap = 0.5; colors = [ "#fb4934" "#b8bb26" "#fabd2f" "#83a598" "#d3869b" "#8ec07c" ]; }'
```

### Flake

```nix
inputs = {
  nix-logo.url = "github:zmberber/nix-logo";
};
outputs = { nix-logo, ... }: {
  packages.x86_64-linux.logo = nix-logo.packages.x86_64-linux.nix-logo-nogap;
  packages.x86_64-linux.my-logo = nix-logo.lib.mkLogo {
    system = "x86_64-linux";
    gap = 0.5;
    colors = [ "#fb4934" "#b8bb26" "#fabd2f" "#83a598" "#d3869b" "#8ec07c" ];
  };
  my-svg = nix-logo.lib.mkSvg { gap = 0.125; };
};
```
